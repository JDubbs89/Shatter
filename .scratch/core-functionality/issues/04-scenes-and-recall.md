# 04: Add scene save, recall, and diff

**What to build:** Users can save named scenes from the current show, inspect differences, and recall a scene with a clear indication of what will change.

**Blocked by:** 03: Persist complete show state robustly.

**Status:** ready-for-agent

- [ ] Users can list, save, rename or replace, and delete named scenes.
- [ ] Users can compare a scene with current state and see changed values before recall.
- [ ] Users can recall a complete scene and confirm the resulting state through listings.
- [ ] Recall failure does not leave the show partially applied.
- [ ] Automated coverage verifies save, diff, recall, and failure behavior.
